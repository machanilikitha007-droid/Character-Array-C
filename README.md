# Character Array in C

**Author:** M.Likitha

## Description

This program demonstrates how to declare and use a character array
to store and display a string.

## File

character_array.c

## Concepts Used

- Character array
- String input
- `fgets()`
- String output

## How to Run

gcc character_array.c -o character_array
./character_array
